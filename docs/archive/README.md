# Plans that are built

These are the plans this repository was built by, each with what building it found. They are kept as the record of why things are as they are, and none is the course any more: `docs/focus-plan.md` is.

- `milestones.md`: the course from the prototype to the MVP surfaces, October 2026.
- `claude-code-prompt.md`: the brief for the first milestone, the typed core.
- `dom-painter-plan.md`: the element, the ratio scene and the fit rules, with its review.
- `feedback.md`: what building the painter plan found, item by item.
- `chart-coverage-plan.md`: the marks and layouts it took to draw the common chart types. Section 8 is what each step found.
- `uncommon-coverage-plan.md`: the same for the uncommon types. Section 7 is what each step found.

They name things as they were then: `v` and `t` where a node now says `y`, presets the library no longer ships, a prototype that is gone.

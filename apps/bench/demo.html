One description of a view, drawn wherever it lands

This is the charting layer for the analytics MVP, and the candidate next version of @automattic/charts. A view is written once, as data. Each place it appears decides how to present it. Everything on this page is the same element, <ua-view>, on fixture data. The controls above are the page's, and every view below follows them.

A view is written once, as data

A spec names a metric and a dimension, never a chart size or an endpoint. Chart types are presets over a small set of marks. Edit the spec and the view follows; break it and the error names the fix.

The same view as words, for an agent, a message or a screen reader:

It fits the room it is given

Nothing here names a size or a breakpoint, and no script runs when a view is resized. Each part knows the room it needs: guides go first, then the comparison, then the marks, down to the number and at last the sentence. Drag the corner of any view.

In a row, as a toolbar would hold them. Each fills the box it is handed:

A surface lays views out; a view never knows where it is

The same specs, in a dashboard of tiles and in a panel at sidebar width. The surface owns the layout, the titles and the shared range. A view fills what it is handed.

The surface also gives each metric its colour, from the qualitative ramps, and a list or a share bar a colour per row. No spec names one:

It reads without the picture

Keyboard. Tab into any chart above. Arrow keys step through its points, and the readout says each one. Enter activates a point, and the view tells its surface which row:

  1. Nothing activated yet. Press Enter on a point, or click one.

Table. Every view carries the same result as a table. Switch "Show as: tables" in the bar above.

Sentence. Every view carries a sentence derived from its query, as its description and as its last resort when there is no room for anything else.

It works from markup alone

No wiring is needed: a spec, a result and a catalog as JSON inside the tag. This is what an agent writes into an artifact, or a server into a page. The view on the right was made from exactly the markup on the left.

The seven things docs/dom-painter-plan.md section 7 asks to be proved before the DOM painter is built. The trend view below is a throwaway custom element, built by hand. Every verdict is computed in this browser when the page loads: open it in Safari and Firefox and read them again.

… 1. Dashes on a stretched path keep their screen length

Each box is one SVG, viewBox="0 0 100 100", stretched to a different size, holding a horizontal and a vertical path dashed 10 10 with vector-effect: non-scaling-stroke. The coloured rulers beside them are plain CSS, 10 px on and 10 px off. Look: every dash should sit on a ruler mark at every size. The numbers are the same SVG drawn to a canvas by this browser and read back, in px. Also look at the dashed comparison line and the dashed tail in the views further down: the dashes should be the same length at every width.

… 2. The nested chain: a view query changes the grid, the plot narrows, a plot query drops the comparison

The frame is a box 130 px tall holding one view. The check sets every width from 420 down to 120 px and, after each, compares what is showing with what the fit rules say for the sizes the browser reports. It does the same on a view at its natural height. No script runs in the view on resize. Look: drag the corner, or play the sweep, and watch for a frame where the comparison shows in a plot too narrow for it.

… 3. CSS.registerProperty animates custom properties used inside a shadow root

A data change moves a y tick that both results share. Its --vg-t is written with style.setProperty and the shadow sheet carries transition: --vg-t 600ms linear. The check reads the computed value and the grid line's position 300 ms in. Look: press the button and the grid lines should slide, not jump.

… 4. container-type: size on the plot behaves inside a grid

For every view on this page: the plot is as tall as the rule set says (184 px with axes, 46 px bare) or as tall as the room left in a box; it takes the width the axis column leaves; the SVG fills it; each y label sits on its grid line; and a plot wide enough but too short drops the comparison on its block-size query alone.

… 5. The stretched monotone path matches a path computed at pixel size

For every plot on this page, the line and the comparison are computed again with d3-shape at the plot's pixel size. 200 points along each are compared with the stretched path as the browser places it on screen (getScreenCTM). The number is the greatest distance found.

… 6. One stylesheet serves both sizings

The same element, with the same adopted sheet and no attributes, in a stack (fills the width, natural height) and in rows (fills the box it is handed). Only the layout's CSS differs, and it is the three rules of section 4.2 as written. Drag any corner.
